## 二、修法（I1 主修 + I2 辅助）

### I1 前端确定性闸口（主修）

- 消费 value-investor verdict 的组件（`ValueAssessmentPanel.tsx` /
  `AnalystReportCard.tsx` / `CompactValueAssessment.tsx`）：当同一份分析结果的
  `t-valuation.dcf.applicable === false` 时，「估值评估」行**不显示**
  `intrinsic_value_range` 字符串，改显示「DCF 不适用：<inapplicable_reason>」
  （与 portfolio-mgr 决策卡 V77 的剔除告知同源同措辞）；
  `margin_of_safety` 同理由该区间派生，一并置灰/隐藏；
- LLM 是否守规矩不再重要——闸口在数据层，判据是结构化布尔，不解析文案；
- 测试：Vitest 用 601399 真实 payload 做 fixture（applicable=false + 违规区间串
  ⇒ 断言渲染「不适用」；applicable=true 的正常样本 ⇒ 区间照常显示，反向锁）。

### I2 prompt 加固（辅助，不承重）

- `value-investor.md` 在硬规则处补一句反例（本次原话），提示「带免责声明的区间
  依然是违规」；正文说明放 report，字段必须 null。
