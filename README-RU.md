## Что такое AxInvest?

**AxInvest v2.3** — это платформа интеллектуального инвестиционного анализа на базе ИИ, построенная на мультиагентной платформе AxAgent. Она глубоко интегрирует продвинутые возможности AI-агентов с профессиональным анализом инвестиций в A-акции, поддерживает нескольких провайдеров моделей, AI-исследования агентов, визуальную оркестрацию рабочих процессов, локальное управление знаниями, встроенный API-шлюз, охватывая пять платформ **Windows / macOS / Linux / Android / iOS**, с адаптивной разметкой для **десктопа, планшета и телефона**.

Ключевая особенность AxInvest — использование механизмов мультиагентной состязательной дискуссии, глубокого исследования и проверки фактов для предоставления всесторонней и объективной аналитической поддержки инвестиционных решений.

## Основные функции

### 📈 Интеллектуальный инвестиционный анализ

Ключевой модуль AxInvest, глубоко интегрирующий возможности AI-агентов с профессиональным инвестиционным анализом:

**Мультиисточниковая агрегация и деградация данных**

- **9 источников данных** — Tencent Finance, Tongdaxin (mootdx), East Money, Sina Finance, Baidu Stocks, THS (Tonghuashun), Iwencai, Cninfo, AKShare
- **22 маршрута данных** — Для каждого типа данных настроена мультиисточниковая деградация маршрутов, автоматическое переключение на резервный источник при недоступности основного
- **Параллельный сбор данных** — `tokio::join!` параллельное извлечение 16 типов данных по отдельным акциям + 5 типов рыночных данных, максимальная эффективность сбора
- **Интеллектуальный кэш** — LRU кэш в памяти (лимит 1000 записей), котировки TTL 30с / K-линии TTL 300с, автоматическое устранение по истечении
- **Проверка работоспособности** — Зонд связности поставщиков (Ping An Bank 000001 как зонд), поддержка обнаружения доступности источников данных во время выполнения

**Идентификация рынка A-акций и правила**

- **Идентификация секторов** — Автоматическая идентификация по префиксу кода: Шанхайская основная доска (6), STAR Market (688), Шэньчжэньская основная доска (0), ChiNext (3), Пекинская биржа (8)
- **Правила предельного повышения/снижения** — STAR Market/ChiNext ±20%, Пекинская биржа ±30%, основная доска ±10%, ST-акции ±5%
- **Торговый календарь** — Встроенные праздники и перенесённые рабочие дни A-акций на 2025-2026 годы, поддержка определения торговых дней

**Данные по отдельным акциям (16 типов)**

- **Котировки в реальном времени** — Цена, изменение, объём/оборот, оборачиваемость, PE/PB, общая капитализация, цена предельного повышения/снижения, ST-идентификатор
- **Данные K-линий** — 7 периодов (5 мин/15 мин/30 мин/60 мин/день/неделя/месяц), включая объём, оборот, оборачиваемость
- **Финансовый анализ** — Выручка, чистая прибыль, EPS, BPS, ROE, коэффициент задолженности, валовая маржа, чистая маржа, рост выручки г/г, рост прибыли г/г
- **Денежные потоки** — Чистый приток: основной/сверхкрупный/крупный/средний/мелкий
- **Рейтинг Dragon-Tiger** — Суммы покупок/продаж отделений, нетто, причина попадания в рейтинг
- **Снятие ограничений на акции** — Дата снятия, количество акций, доля снятия, информация об акционерах
- **Маржинальная торговля** — Сумма покупки в маржу/остаток, объём короткой продажи/остаток
- **Северный капитал** — Количество акций, доля владения, изменение количества
- **Отраслевая классификация** — Отрасли Шэньвань 1-го/2-го уровня, теги концептуальных секторов
- **Изменения долей акционеров** — Динамика увеличения/уменьшения долей ключевых акционеров, причины изменений
- **История дивидендов** — Дата экс-дивиденда, дивиденд на акцию, коэффициент сплита/бонуса, дата регистрации
- **Агрегация исследований** — Брокерские исследования, включая организацию, аналитика, рейтинг, целевую цену, прогноз EPS
- **Консенсус-прогноз EPS** — Консенсус-прогноз EPS институтов, консенсус-целевая цена, средний рейтинг, количество рейтингов
- **Концептуальные сектора** — Трёхмерная принадлежность (отрасль/концепция/регион), включая изменение цен в секторе
- **Поиск объявлений** — Объявления листинговых компаний через Cninfo, включая тип объявления и ссылку на PDF
- **Новости и настроения** — Заголовки/резюме/источники новостей, включая оценку настроений

**Рыночные данные (5 типов)**

- **Общерыночный рейтинг Dragon-Tiger** — Все акции в рейтинге за день, включая нетто-покупку, суммы покупок/продаж
- **Популярные акции** — Сильные акции THS, включая изменение, оборачиваемость, теги причин, принадлежность к сектору
- **Отраслевые рейтинги** — Изменение отраслей Шэньвань, оборот, лидеры роста
- **Новости Cailianshe** — Новости в реальном времени, включая заголовок, содержание, источник
- **Потоки северного капитала** — Минутные потоки капитала Шанхай/Шэньчжэнь/итого

**Расчёт технических индикаторов (модуль indicators)**

- **Система скользящих средних** — MA5/MA10/MA20/MA60, включая определение состояния выравнивания (бычье/медвежье/слабое бычье/переплетение)
- **MACD** — DIF/DEA/гистограмма, включая определение сигналов (золотой крест/мёртвый крест/бычье движение/медвежье движение)
- **RSI** — RSI6/RSI12/RSI24, включая определение сигналов (перекупленность/перепроданность/сила/слабость/нейтрально)
- **Полосы Боллинджера** — Верхняя/средняя/нижняя полоса (20,2), включая определение позиции (выше верхней/верхняя зона/около средней/нижняя зона/ниже нижней)
- **Коэффициент отклонения** — Коэффициент отклонения MA5, коэффициент отклонения MA20
- **Анализ объёма** — Отношение объёмов (объём дня / средний объём за 5 дней), включая определение сигналов (рост на объёме/откат на снижении/падение на объёме/рост на снижении/нормально)
- **Уровни поддержки/сопротивления** — Автоматический расчёт на основе недавних максимумов/минимумов и скользящих средних

**Регистрация MCP-инструментов (модуль mcp_tools)**

- Возможности данных по акциям регистрируются как стандартные инструменты через протокол MCP, AI-агенты могут вызывать их непосредственно в диалоге
- Зарегистрированные инструменты: search_stock, get_stock_quote, get_stock_kline, get_stock_financials, get_stock_news, get_stock_money_flow, get_stock_dragon_tiger и др.

**AI-конвейер анализа (крейт stock-analysis, 23 подмодуля)**

- **Оркестрация анализа** — orchestrator (оркестрация конвейера), pipeline (многостадийный конвейер), runner (исполнитель задач)
- **Движок решений** — decision (инвестиционные решения), signals (генерация торговых сигналов), rules (движок торговых правил)
- **Оценка рисков** — risk (модели оценки рисков), portfolio_risk (риск портфеля), position_limits (лимиты позиций и комплаенс)
- **Скринер и бэктестинг** — screener (многокритериальный скринер), backtest (движок бэктестинга стратегий), trading (фреймворк торговых стратегий)
- **Стоимостное инвестирование** — value (анализ стоимости), value_investing (фреймворк оценки стоимостного инвестирования)
- **Контроль качества** — quality (проверка качества данных), data_clean (очистка и предобработка данных), review (ревью результатов анализа)
- **Отчёты и скоринг** — report (генерация аналитических отчётов), scoring (система комплексного скоринга)
- **Вспомогательные модули** — key_levels (идентификация ключевых уровней), monitor (мониторинг и оповещения в реальном времени), plugin (расширения плагинов анализа), prompts (шаблоны AI-промптов)

### 🔐 Система AI-агентов

Система агентов построена на сложной архитектуре (крейт agent, 70+ исходных файлов) со следующими характеристиками:

- **Механизм рассуждений ReAct** — Слияние рассуждений и действий со встроенной самопроверкой для надёжного выполнения задач
- **Иерархический планировщик** — Декомпозиция сложных задач в структурированные планы с фазами и зависимостями
- **Декомпозитор задач** — Автоматическая декомпозиция сложных задач в выполнимые подзадачи
- **Цепочка мыслей** — Визуализация процесса принятия решений агентом, пошаговая декомпозиция
- **Дерево мыслей** — tree_of_thoughts мультипатчевое исследование рассуждений
- **Глубокое исследование** — Многоисточниковая оркестрация поиска, отслеживание цитирования и оценка достоверности
- **Проверка фактов** — Проверка фактов на базе ИИ и классификация источников
- **Оркестрация поиска** — Координация нескольких поисковых провайдеров с планированием поиска и синтезом результатов
- **Академический поиск** — Поиск академической литературы и анализ цитирования
- **Управление компьютером** — Управляемые ИИ клики мыши, ввод с клавиатуры, прокрутка экрана с анализом визуальной модели
- **Восприятие экрана** — Захват скриншотов и анализ визуальной моделью для идентификации элементов UI
- **Визуальный конвейер** — vision_pipeline понимание и анализ изображений
- **Три уровня разрешений** — По умолчанию (требуется одобрение), Принимать изменения (автоодобрение), Полный доступ (без запросов)
- **Изоляция песочницы** — Операции агента строго ограничены указанным рабочим каталогом
- **Панель одобрения инструментов** — Отображение в реальном времени запросов на вызов инструментов с индивидуальным одобрением
- **Отслеживание расходов** — Отображение в реальном времени использования токенов и статистики расходов по сессиям
- **Пауза/Возобновление** — Приостановка выполнения агента в любой момент и возобновление позже
- **Система контрольных точек** — Постоянные контрольные точки для восстановления после сбоев и переподключения сессий
- **Механизм восстановления ошибок** — Автоматическая классификация ошибок, анализ корневых причин и выполнение стратегий восстановления
- **Обнаружение циклов** — Автоматическое обнаружение и прерывание циклического поведения в рассуждениях агента
- **Проактивный режим** — Агент может проактивно предлагать рекомендации и выполнять действия
- **Управление целями** — Поддержание и отслеживание целей выполнения и контекста агента
- **Самопроверка** — self_verifier автоматическая проверка корректности вывода агента
- **Рефлексор** — reflector рефлексия и улучшение процесса рассуждений
- **Управление направлением** — steer_manager динамическая корректировка направления поведения агента
- **Шина событий** — event_bus / event_emitter событийно-ориентированная архитектура агента
- **Синтез контента** — content_synthesizer многоисточниковый синтез информации и генерация отчётов
- **Отслеживание цитирования** — citation_tracker автоматическое отслеживание и аннотирование источников информации
- **Оценка достоверности** — credibility_evaluator оценка достоверности источников информации
- **Построение структуры** — outline_builder автоматическое построение структуры исследования
- **Управление схемами** — schema_manager управление схемами выходных структур
- **Память проекта** — project_memory постоянная память на уровне проекта
- **Зондирование окружения** — environment_probe автоматическое обнаружение информации о среде выполнения
- **Проверка работоспособности** — health_checker мониторинг состояния работоспособности агента

### 👥 Мультиагентное сотрудничество

- **Координация подагентов** — Архитектура ведущий-ведомый, coordinator координирует несколько коллаборативных агентов
- **Параллельное выполнение** — Параллельная обработка несколькими агентами с учётом зависимостей при планировании
- **Состязательная дискуссия** — adversarial_debate раунды дебатов Pro/Con, поддержка оценки силы аргументов и отслеживания опровержений
- **Роли агентов** — agent_roles предопределённые роли (исследователь, планировщик, разработчик, рецензент, синтезатор) для командной работы

- **Граф коммуникации** — graph_insights визуализация взаимодействий и потоков сообщений между агентами
- **Общая доска** — shared_blackboard / blackboard разделяемое пространство состояния между агентами
- **Система Buddy** — Настраиваемые агенты-партнёры с определением видов и атрибутов
- **Общая память** — Разделяемое пространство памяти между агентами со статистикой и запросами
- **Командный Cron** — Планирование задач cron на уровне команды
- **Система экспертов** — agency_expert экспертный агент предметной области
- **Профиль агента** — agent_profile управление профилем личности и возможностей агента

### 🔄 Система рабочих процессов

Движок рабочих процессов (крейт rt-workflow) реализует систему оркестрации задач на основе DAG:

- **Визуальный редактор рабочих процессов** — Конструктор рабочих процессов с перетаскиванием с подключением и настройкой узлов
- **16 типов узлов** — Триггер, агент, LLM, условие, параллельный, цикл, слияние, задержка, инструмент, код, подпроцесс, векторный поиск, анализ документа, валидация, конец, откат (fallback)
- **16 панелей свойств** — Отдельная панель конфигурации для каждого типа узла
- **Шаблоны рабочих процессов** — Встроенные пресеты: ревью кода, исправление багов, документация, тестирование, рефакторинг, исследование, производительность, безопасность, разработка функциональности
- **Выполнение DAG** — Топологическая сортировка по алгоритму Кана с обнаружением циклов
- **Параллельное планирование** — Конвейерное выполнение, быстрые шаги не ждут медленные
- **Стратегия повторных попыток** — Экспоненциальный откат, настраиваемое максимальное количество попыток на шаг
- **Частичное завершение** — Неудачные шаги не блокируют независимые последующие шаги
- **Управление версиями** — Контроль версий шаблонов рабочих процессов с откатом
- **История выполнения** — Подробная запись с отслеживанием состояния и отладкой
- **ИИ-ассистирование** — Проектирование рабочих процессов с помощью ИИ, рекомендация узлов и оптимизация промптов агентов
- **Семантическая проверка** — Семантическая валидация рабочих процессов, обнаружение потенциальных проблем
- **Импорт n8n** — Поддержка импорта рабочих процессов из каталога n8n
- **Панель отладки** — Отладка в реальном времени и просмотр состояния во время выполнения рабочего процесса
- **Слой кэша** — cache_layer кэширование результатов выполнения рабочих процессов
- **Маркетплейс** — workflow_marketplace маркетплейс шаблонов рабочих процессов и рецензирование

- **Четырёхуровневая система защиты** — L1 обнаружение паттернов (перехват высокого риска + маркировка среднего риска) → L2 экранирование разделителей → L3 XML-обёртка → L4 теги доверия
- **Оркестратор конвейера** — Многоуровневый конвейер обнаружения, поддержка настраиваемых порогов риска
- **Обнаружение Token Smuggling** — Специализированное обнаружение против обфускации кодирования и атак контрабанды токенов
- **Обнаружение экранирования разделителей** — delimiter_escape обнаружение атак экранирования разделителей промптов
- **Обнаружение паттернов** — pattern_detect regex + эвристическое сопоставление паттернов инъекций
- **Теги доверия** — trust_labels маркировка и верификация доверенного контента
- **Строгий режим** — Тестирование строгого режима + именование причин среднего риска + документация пользовательских режимов
- **Полная интеграция конвейера** — Интегрировано в session / prompt / git / RAG на всех этапах

### 📱 Поддержка мобильных устройств

- **Нативный Android** — Сборка APK/AAB, поддержка arm64-v8a / armeabi-v7a / x86_64
- **Нативный iOS** — Сборка IPA, поддержка arm64
- **Адаптивная разметка** — Трёхуровневая автоматическая адаптация десктоп/планшет/телефон (хук useResponsive)
- **Мобильная навигация** — Выдвижная навигация Drawer + нижняя панель навигации + всплывающая плавающая кнопка
- **Адаптация безопасных зон** — CSS env() адаптация для системной строки состояния/навигации Android
- **Оптимизация CSP** — Белый список CSP-протоколов для Android WebView
- **Условная компиляция** — `#[cfg(not(mobile))]` автоматическое исключение десктоп-функций (браузер, управление компьютером, десктоп, QuickBar, терминал, восприятие экрана)

## Быстрый старт

### Загрузка готовых сборок

Посетите страницу [Releases](https://github.com/polite0803/AxAgent/releases) для загрузки установщика вашей платформы.

### Сборка из исходного кода

#### Предварительные требования

- [Node.js](https://nodejs.org/) 20+
- [Rust](https://www.rust-lang.org/) 1.75+
- [npm](https://www.npmjs.com/) 10+
- Windows: [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) + цели Rust MSVC

#### Шаги сборки

```bash
# Клонировать репозиторий
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent

# Установить зависимости
npm install

# Режим разработки
npm run tauri dev

# Собрать только фронтенд
npm run build

# Собрать десктоп-приложение
npm run tauri build
```

Артефакты сборки находятся в `src-tauri/target/release/`.

### Тестирование

```bash
# Модульные тесты
npm run test          # Vitest watch
npm run test:run      # Vitest однократный запуск

# E2E-тесты
npm run test:e2e      # Playwright
npm run test:e2e:ui   # Playwright UI-режим

# Тесты Rust-бэкенда
cd src-tauri && cargo nextest run   # cargo-nextest (быстрее в 2-3x)
cd src-tauri && cargo test          # Стандартные тесты

# Проверка типов
npm run typecheck     # TypeScript
cd src-tauri && cargo clippy -- -D warnings  # Rust

# Форматирование кода
npm run format        # dprint
cd src-tauri && cargo fmt

# CI-проверка
npm run ci:check
```

## Часто задаваемые вопросы

### macOS: «Приложение повреждено» или «Невозможно проверить разработчика»

Поскольку приложение не подписано Apple:

**1. Разрешить приложения из «Любого источника»**
```bash
sudo spctl --master-disable
```

Затем перейдите в **Системные настройки → Конфиденциальность и безопасность → Безопасность** и выберите **Любой источник**.

**2. Удалить атрибут карантина**
```bash
sudo xattr -dr com.apple.quarantine /Applications/AxInvest.app
```

**3. Дополнительный шаг для macOS Ventura+**
Перейдите в **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть**.
