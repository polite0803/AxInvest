# PLAN：DCF 适用性门被代理锚「自我论证」——亏损公司三档全是利好（301302 实证）

日期：2026-09-27 · 状态：已批准并实施——E1 提交 `4e5e011eb`（定点 clippy `--all-targets -D warnings` 绿、`cargo test -p axagent-astock-data --lib mcp_tools` 42/42 绿，含 301302 实参复刻与缺数态反向锁）；D4（面板空回归修复）另提交 `f11579c5b`（模板 v87）；剩 E2/D3 = 重启应用重跑 301302 核对 · 上游事件：`PLAN-live-kline-cache-calendar-storm.md` ②号问题（用户：「现价=估值下限 ⇒ 必涨，凭什么观望」）

## 一、现象

301302（华如科技）16:54 运行 `2bb5bb9d`：巴菲特估值结论「21.17–71.86 元」，现价 21.72 ⇒
面板「上行空间 -2.5%」。用户质疑：现价已等于三档下限，估值视角「必涨」，决策却观望 ⇒
要求查估值算法为什么错得离谱。

## 二、取证链（库内数值 + 代码逐条对账）

**标的事实形态**（同运行 `t-fundamentals-data`）：
净利率 **-34.9%**、ROE -13.9%、静态 PE **-15.75**（TTM 亏损）、营收同比 **+74.8%**、
资产负债率仅 14.6%。即「增收不增利、结构性转亏」。

**模型输入**（`t-valuation.dcf.assumptions`）：
- `is_fallback_anchor=true`：当期 TTM FCF ≤ 0（`fcf_data_missing=false`，是真负不是缺数）⇒
  锚改用**近 5 年报正净利均值 × 0.90 = 1.133 亿**（`mcp_tools.rs:3030` `normalized_annual_profit`）；
- `growth=0.30`（营收同比 74.8% 被 `MAX_GROWTH=0.30` 封顶，`mcp_tools.rs:3065`）；
  三档 = 0.30 × {0.6, 1, 1.5} = **18% / 30% / 45%**（`mcp_tools.rs:3173/3199`）；
- `terminal_value_ratio=0.817`：81.7% 的估值来自永续终值（折现率 7.7% / 永续 1.3% 全市场常量）。

**适用性门逐条放行原因**（`compute_dcf` 判据 ①②④⑤，`mcp_tools.rs:3231-3397`）：

| 判据 | 应拦什么 | 301302 为何穿过 |
|---|---|---|
| ① 杠杆 >70% | 净利由权益乘数驱动 | 负债率 14.6% ⇒ 合理放行 |
| ② 净利>0 且 FCF≤0/背离 | 账面盈利现金流出 | `ttm_net_profit ≤ 0` ⇒ 整段 filter 短路（设计上由 ④ 接手） |
| ④ 净利≤0 且**锚定** FCF 收益率 <3% | 「市场不按当期现金流定价」的极端亏损 | **收益率分子用的是 fallback 后的代理锚**（`mcp_tools.rs:3352` `fcf_yield = fcf / market_cap`，此 `fcf` 即 3028 行锚定后的 1.133 亿）⇒ 1.133/30.2 = **3.75% > 3%**，以「历史黄金年份的利润收益率」为当期现金流定价判据放行。真实当期 FCF ≤ 0，若用 `direct_fcf` 该判据**必然命中** |
| ⑤ 永续配置越界 | 配置把模型推进发散区 | 1.3% 未越界 ⇒ 合理放行 |

**要害**：判据 ② 的注释（`mcp_tools.rs:3021`）已经写明了这个教训——「② 必须看 `direct_fcf`
而不是 fallback 后的代理值，代理值恒 ≈ 0.9×净利，会把最强信号抹掉」。② 修了（2026-09-14 提升
`direct_fcf` 到外层），**2026-09-21 新增 ④ 时没吃同一个教训**：④ 的立身理由（`mcp_tools.rs:3333`
原文「亏损公司（恰恰最该质疑 FCF 折现前提）反而落 applicable=true」）在「当期 FCF 真为负」的
主形态上被代理锚自我论证掉了。688114 样本（锚收益率 1.18%）能命中，恰因它连历史利润都撑不起
市值；而 301302 这种「历史 profitable、当期转亏」的目标形态全数漏网。

**概念层的次生问题（由上表派生，不单改）**：对亏损公司，三档 18/30/45% 增长全部建立在
「恢复到近 5 年好年份利润水平之上再年化增长」的假设上——**「low 档」并不是风险档，而是最弱的
利好档**；真正的最差情景（恢复不了、持续失血）在模型里不存在。这正是「现价=下限⇒看起来必涨」
的构造来源。格雷厄姆腿 +287.9% 同为公式化输入产物（`growthClamped=true`，已被决策链 ×0.5 衰减）。

## 四、修复阶段（逐阶段批准推进）

### E1 核心修复：判据 ④ 补「当期 FCF 符号」直判（`astock-data/mcp_tools.rs`）

- 在 ④ 现有「锚定收益率 <3%」之外**加一条并列形态**：
  `ttm_net_profit ≤ 0` **且** `direct_fcf = Some(v ≤ 0)` ⇒ 判不适用，
  理由文案含真实当期 FCF 数值（不复用代理锚做证据）；
- **缺数态（`direct_fcf=None`）维持现状**——「缺数据 ≠ 模型不成立」原则不破，
  300308 三样本行为不变；净利>0 的公司不进 ④（仍归 ②），300642/601166 既有回归锁不动；
- 测试：新增 `dcf_inapplicable_when_ttm_loss_and_current_fcf_negative`（用 301302 实参复刻：
  锚 1.133 亿 / 市值 30.2 亿 / TTM 净利<0 / direct FCF<0 ⇒ signals 非空、applicable=false）；
  反向锁：同锚但 direct_fcf>0 ⇒ 不命中；同锚、净利>0、FCF<0 ⇒ 由 ② 命中（防串扰）。
- 下游联动（**零改动，验证即可**）：`applicable=false` ⇒ portfolio-mgr V77 整腿剔除 DCF、
  `valuationApplicability.dcfApplicable=false`、决策卡 reasoning 自动带
  「⚠️估值(DCF)不适用已剔除：<inapplicable_reason>」（`portfolio-mgr.rhai:2418`），
  面板不再出现「21.17–71.86 / -2.5%」与观望并置的打脸画面。
- 语义修正幅度评估：这是把 ④ 的原设计（「连历史盈利都撑不起市值才拦」）收紧为
  「当期既亏损又失血 ⇒ 归一化锚无资格做折现基础」。拦下的正是本次 6/9 样本。
