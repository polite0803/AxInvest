## 二、核心：f5 三条腿互相抵消

### 输入（全部来自 `blackboard_snapshot` 实测，非推测）

| 腿 | 数据源 | 原始值 | σ_leg | 权重 | 加权贡献 |
|---|---|---|---|---|---|
| DCF | `t-valuation.dcf.upsidePct` | **+92.8%** | `+0.6988` | 0.56 | **+0.3913** |
| graham | `t-valuation.graham.upsidePct` | **−84.0%** | `−0.6774` | 0.24 | **−0.1626** |
| PE 分位 | `t-valuation-band.metricPe.currentPercentile` | **99.9557** | `−0.9991` | 0.20 | **−0.1998** |
| | | | | `Σw=1.0` | **+0.0289** |

`× fscore_mult(1.3) × moat_mult(1.0)` ⇒ **`f5 σ = +0.0376`**（DB 实测 `0.038`）

### 为什么这是**类别错误**

三条腿衡量的**不是同一个量**，却被等权算术平均：

- **DCF** = 绝对估值，锚是 **当期自由现金流 1.35 亿元**（`fcf_anchor=135216581`）
- **graham** = 绝对估值，锚是 **EPS 0.076 元**（`intrinsicValue 3.35 ÷ multiplier 44.1`）
- **PE 分位** = 相对估值，只问「当前 PE 在自己 5 年分布里的位置」（1179 个交易日样本，当前第 **99.96 分位**）

**同一个公司的两个绝对锚差 12.9 倍**：

```
FCF 锚      = 13,521.7 万元
净利（反解）= EPS 0.076 × 总股本 137,725,975 = 1,046.7 万元
FCF / 净利  = 12.9 倍
```

而 DCF 适用性门（`portfolio-mgr.rhai:623-627`）只拦「FCF **太低**」（`FCF/净利 < 0.3` 或符号相反），**不拦「FCF 过高」** ⇒ `applicability_signals: []`（DB 实测为空）⇒ DCF 腿以满强度 `+0.6988` 入场。

> ⇒ **一个 FCF 是净利 12.9 倍的标的，DCF 说低估 92.8%，PE 说史上最贵（99.96 分位），graham 说高估 84%。三条腿不是在「平均独立证据」，是在「平均三个互相矛盾的公司」。** 净结果 ≈ 0 是必然而非巧合。

### 副作用：观测面缺一腿

`decision_json.valuationApplicability` 只落 `dcfLegUsed` / `grahamLegUsed`，**没有 `bandLegUsed`**（`portfolio-mgr.rhai:224-231` 区块）。
⇒ 三腿时代，落库观测面仍停两腿 ⇒ 下一轮审计**看不到 PE 分位腿参与了**。本次是靠手算才发现权重 0.20 被吃掉。

## 四、天花板论证（回答「调阈值能不能救」）

```
买入档需 effective_posterior ≥ 0.63
            ⇒ posterior ≥ 0.71（高风险档 risk_bias = −0.08）
            ⇒ avg_signal ≥ (0.71 − 0.5) / evidence_scale(0.5558) = 0.3848
            ⇒ Σ(σᵢwᵢ) ≥ 0.3848 × 1.462 = 0.5626
```

当前 `Σ(σᵢwᵢ) = 0.0363`（差 **15.5 倍**）。构造两个天花板：

| 天花板场景 | avgSignal | eff | 动作 |
|---|---|---|---|
| 所有 `σ<0` 归零（f5 保持 0.038） | 0.1374 | 0.4950 | 持有 |
| 所有 `σ<0` 归零 **且** f5 拉满 `+1.0` | 0.2460 | 0.5542 | **增持（仍非买入）** |

⇒ **结论是「结构性不可达」，不是「坏消息太多」。** 降阈值只能重新定义档位语义（语义降级），不能提升能力。

**约束来自哪**（负向因子权重合计 0.49，且都是强负）：

| 因子 | σ | 权重 | 贡献 | 说明 |
|---|---|---|---|---|
| f2 consensus | −0.300 | 0.250（最大） | −0.0750 | 共识评分 35 分 |
| f4 risk | −0.328 | 0.150 | −0.0492 | 年化波动 90.8%、ROE 0.9% |
| f9 money_flow | −0.381 | 0.090 | −0.0343 | 主力资金流出 |
| **f6 data_quality** | **0.000** | **0.150** | **0** | 纯稀释 |
| **f7 trade_signal** | **0.000** | **0.100** | **0** | 纯稀释 |
| **f5 valuation** | **+0.038** | **0.165** | **+0.0063** | 三腿抵消 |

**零信号因子在 24 条样本里的频率**：`f7 σ=0` **8/24（33%）**、`f6 σ=0` **9/24（37.5%）**、`f5 σ∈[−0.1,0.1]` **5/24（21%）**。
⇒ `0.15 + 0.10 = 0.25` 权重（占 `total_weight` 的 **17%**）在相当比例样本上空转。

**f6 σ=0 是设计**（`portfolio-mgr.rhai:886-890`，V75：`dqi≥50 → 0`，"数据够用即中性"）；
**f7 σ=0 是分支缺失**（`portfolio-mgr.rhai:959-963`）：

```rhai
if dir.contains("看多") … { 正 }
else if dir.contains("看空") … { 负 }
else { 0.0 }        // ← trader_direction = "中性" 落这里
```

实测 `trader.content.verdict.verdict = "中性"`（`llm_decision_json` 已验证，映射链无断）⇒ f7 = 0。
**⇒ trader 的 `confidence=58`、`evidence_cited` 5 条、`riskLevel=高风险` 三重调制全部作废**，只因为它把方向词写成了「中性」。同时 `posterior_cap` 一票否决也失效（`f7_signal` 永不 < −0.35）。

> 一个占 10% 权重的因子在「中性」档输出 0，数学上等价于**把所有其他信号整体乘 0.9**。

## 五、展示层撕裂：目标价恒 `—`，止损价却来自另一个世界

### 数据事实

| 字段 | 公式侧 `portfolio-mgr.rhai` | LLM trader 侧 | 展示用了谁 |
|---|---|---|---|
| 仓位 | **9.4%** | **0%**（原文「观望不建仓」） | 公式侧 |
| 止损 | `stopLossPct=8%` ⇒ **19.34 元** | `stopLoss = 17.9`（−14.8%） | **LLM 侧** |
| 目标价 | `takeProfitPct=18%` ⇒ **24.80 元** | `targetPrice = null` | **LLM 侧 → `—`** |

### 代码根因

`analysis-engine/src/dashboard_report.rs:518-519`：

```rust
let target_price = decision_json.get("targetPrice").and_then(|v| v.as_f64());
let stop_loss    = decision_json.get("stopLoss").and_then(|v| v.as_f64());
```

而 `stock_workflow/decision.rs:3343-3345` 的注释**已经写明这件事**：

> `portfolio-mgr.rhai` 的 `decision_json` **只输出百分比**（`stopLossPct`/`takeProfitPct`），
> **从不产出绝对价格** ⇒ 公式侧 `targetPrice`/`stopLoss` 键**永远不存在**（DB 实证 603466），
> 本函数因此**恒命中**。

**⇒ 已知的缺口，却用「去读一个永远不存在的键」来填。** 唯一补位来源是 LLM 自填的 `verdict.targetPrice` / `verdict.stopLoss`，于是：

1. **多头侧信息永久丢失** —— 公式明明算出了止盈 24.80，被丢弃；
2. **空头侧显示了错误的口径** —— LLM 的 −14.8% 与公式的 −8% 打架，用户看到的是前者；
3. **`targetPrice=null` 是 LLM 的合理决策**（原文：「由于 action 为观望，不输出方向性 targetPrice」）—— 是展示层**把 null 当作了「没有目标价」**，而正确语义是「公式侧有，取公式侧」。

### 同一现象的第二处证据

`stock_analysis.rs:357-358` 落库的是 `stop_loss_pct` / `take_profit_pct`（**百分比**）——
**系统内部真的有两套字段同时在跑，展示层挑错了那套。**

## 八、反事实的可证伪不变量（供下一轮一步对账）

写进 `portfolio-mgr.rhai` 注释 / 落库：

```
Σ(σᵢ·wᵢ) / Σwᵢ  ==  evidence.avgSignal（落库 round 2 位内）
fused_sig × fscore_mult × moat_mult  ==  evidence.factors.f5.sigma
posterior − prior  ==  avg_signal × (0.10 + 0.45·√(total_weight/max_weight))
```

第三条在本样本实测 `0.0141 = 0.0254 × 0.5558` ✅。
