## AxInvest क्या है?

**AxInvest v2.3** एक AI-संचालित बुद्धिमान निवेश विश्लेषण प्लेटफॉर्म है, जो AxAgent मल्टी-एजेंट फ्रेमवर्क पर बनाया गया है। यह उन्नत AI एजेंट क्षमताओं को पेशेवर A-शेयर निवेश विश्लेषण के साथ गहराई से एकीकृत करता है, बहु-मॉडल प्रदाताओं, AI एजेंट शोध, विज़ुअल वर्कफ़्लो ऑर्केस्ट्रेशन, स्थानीय ज्ञान प्रबंधन, अंतर्निहित API गेटवे का समर्थन करता है, **Windows / macOS / Linux / Android / iOS** पाँच प्लेटफ़ॉर्म को कवर करता है, और **डेस्कटॉप, टैबलेट, फ़ोन** तीन स्तरों के लिए अनुकूली लेआउट प्रदान करता है।

AxInvest की मुख्य विशेषता यह है कि यह मल्टी-एजेंट विरोधात्मक बहस, गहन शोध और तथ्य जाँच जैसे तंत्रों का उपयोग करके निवेश निर्णयों के लिए व्यापक और वस्तुनिष्ठ विश्लेषण समर्थन प्रदान करता है।

## मुख्य विशेषताएँ

### 📈 बुद्धिमान निवेश विश्लेषण

AxInvest का मुख्य विशेषता मॉड्यूल, AI एजेंट क्षमताओं को पेशेवर निवेश विश्लेषण के साथ गहराई से एकीकृत करता है:

**बहु-स्रोत डेटा एकत्रीकरण और अवनति**

- **9 बड़े डेटा स्रोत** — टेंसेंट वित्त, टोंगडैक्सिन (mootdx), डोंगफांग कैफू, सिना वित्त, बाइडू स्टॉक, टोंगहुशुन (THS), वेनकै (Iwencai), जूचाओ सूचना (cninfo), AKShare
- **22 डेटा राउटिंग** — प्रत्येक डेटा प्रकार के लिए बहु-स्रोत अवनति राउटिंग कॉन्फ़िगर की गई, प्राथमिक स्रोत अनुपलब्ध होने पर स्वचालित रूप से बैकअप स्रोत पर स्विच
- **समवर्ती डेटा संग्रह** — `tokio::join!` से 16 प्रकार के व्यक्तिगत शेयर डेटा + 5 प्रकार के बाजार डेटा का समवर्ती प्राप्ति, संग्रह दक्षता को अधिकतम
- **बुद्धिमान कैशिंग** — LRU मेमोरी कैश (1000 प्रविष्टि सीमा), उद्धरण 30s TTL / K-लाइन 300s TTL, स्वचालित समाप्ति निष्कासन
- **स्वास्थ्य जाँच** — प्रदाता कनेक्टिविटी प्रोब (पिंग एन बैंक 000001 प्रोब के रूप में), रनटाइम पर डेटा स्रोत उपलब्धता का पता लगाने का समर्थन

**A-शेयर बाजार पहचान और नियम**

- **बोर्ड पहचान** — कोड उपसर्ग के आधार पर स्वचालित पहचान: शंघाई मेनबोर्ड (6), STAR मार्केट (688), शेन्ज़ेन मेनबोर्ड (0), ChiNext (3), बीजिंग स्टॉक एक्सचेंज (8)
- **उच्चतम/न्म्नतम सीमा नियम** — STAR मार्केट/ChiNext ±20%, बीजिंग स्टॉक एक्सचेंज ±30%, मेनबोर्ड ±10%, ST शेयर ±5%
- **ट्रेडिंग कैलेंडर** — अंतर्निहित 2025-2026 A-शेयर छुट्टियाँ और समायोजित कार्य दिवस, ट्रेडिंग दिवस निर्धारण का समर्थन

- **संसाधन शासन** — एजेंटों द्वारा संसाधन उपयोग की सीमा और शासन
- **LAN ट्रांसफ़र** — स्थानीय नेटवर्क पर फ़ाइल स्थानांतरण क्षमता
- **सह-विकास** — coevolution कौशल और एजेंट सह-विकास
- **व्यवहार शिक्षण** — behavior_learner / behavior_tracker उपयोगकर्ता व्यवहार शिक्षण और ट्रैकिंग
- **वरीयता शिक्षण** — preference_learner उपयोगकर्ता वरीयताओं का स्वचालित शिक्षण
- **आंतरिक पुरस्कार** — intrinsic_reward आंतरिक प्रेरणा-संचालित अन्वेषण
- **प्रक्रिया पुरस्कार** — process_reward प्रक्रिया-स्तरीय पुरस्कार सिग्नल
- **TextGrad** — text_grad पाठ-ग्रेडिएंट-आधारित स्वचालित अनुकूलन
- **प्रक्षेपपथ संपीड़न** — trajectory_compressor लंबे प्रक्षेपपथ का स्वचालित संपीड़न
- **अनुस्मारक प्रबंधन** — reminder_manager बुद्धिमान अनुस्मारक शेड्यूलिंग
- **कार्य प्रीफ़ेच** — task_prefetcher भविष्यवाणीात्मक कार्य संसाधन प्रीफ़ेच

### 🛡️ प्रॉम्प्ट इंजेक्शन सुरक्षा (Prompt-Guard)

- **चार-स्तरीय सुरक्षा प्रणाली** — L1 पैटर्न पहचान (उच्च-जोखिम अवरोधन + मध्यम-जोखिम मार्किंग) → L2 सीमांकक एस्केपिंग → L3 XML रैपर → L4 विश्वास टैग
- **Pipeline ऑर्केस्ट्रेटर** — बहु-स्तरीय पहचान पाइपलाइन श्रृंखला, अनुकूलन योग्य जोखिम थ्रेसहोल्ड का समर्थन
- **Token Smuggling पहचान** — एन्कोडिंग ओबफ़स्केशन और token smuggling हमलों के खिलाफ विशेष पहचान
- **सीमांकक एस्केप पहचान** — delimiter_escape प्रॉम्प्ट सीमांकक एस्केप हमलों का पता लगाना
- **पैटर्न पहचान** — pattern_detect regex + heuristic इंजेक्शन पैटर्न मिलान
- **विश्वास टैग** — trust_labels विश्वसनीय सामग्री मार्किंग और सत्यापन
- **Strict मोड** — सख्त मोड परीक्षण + मध्यम-जोखिम कारण नामकरण + कस्टम मोड दस्तावेज़ीकरण
- **पूर्ण पाइपलाइन एकीकरण** — session / prompt / git / RAG सभी चरणों में एकीकृत

## त्वरित शुरुआत

### पूर्व-निर्मित संस्करण डाउनलोड करें

अपने प्लेटफ़ॉर्म के इंस्टॉलर डाउनलोड करने के लिए [Releases](https://github.com/polite0803/AxAgent/releases) पृष्ठ पर जाएँ।

### स्रोत कोड से बिल्ड करें

#### पूर्वापेक्षाएँ

- [Node.js](https://nodejs.org/) 20+
- [Rust](https://www.rust-lang.org/) 1.75+
- [npm](https://www.npmjs.com/) 10+
- Windows: [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) + Rust MSVC लक्ष्य

#### बिल्ड चरण

```bash
# रिपॉज़िटरी क्लोन करें
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent

# निर्भरताएँ इंस्टॉल करें
npm install

# विकास मोड
npm run tauri dev

# केवल फ़्रंटएंड बिल्ड करें
npm run build

# डेस्कटॉप एप्लिकेशन बिल्ड करें
npm run tauri build
```

बिल्ड आर्टिफैक्ट्स `src-tauri/target/release/` में हैं।

### परीक्षण

```bash
# यूनिट टेस्ट
npm run test          # Vitest watch
npm run test:run      # Vitest एकल रन

# E2E टेस्ट
npm run test:e2e      # Playwright
npm run test:e2e:ui   # Playwright UI मोड

# Rust बैकएंड टेस्ट
cd src-tauri && cargo nextest run   # cargo-nextest (2-3x तेज़)
cd src-tauri && cargo test          # मानक परीक्षण

# टाइप चेक
npm run typecheck     # TypeScript
cd src-tauri && cargo clippy -- -D warnings  # Rust

# कोड फ़ॉर्मेटिंग
npm run format        # dprint
cd src-tauri && cargo fmt

# CI जाँच
npm run ci:check
```

```
~/.axinvest/                     # कॉन्फ़िगरेशन निर्देशिका
├── axinvest.db                  # SQLite डेटाबेस
├── master.key                   # AES-256 मास्टर कुंजी
├── vector_db/                   # वेक्टर डेटाबेस (sqlite-vec)
└── ssl/                         # SSL प्रमाणपत्र

~/Documents/axinvest/           # उपयोगकर्ता फ़ाइल निर्देशिका
├── images/                     # छवि अनुलग्नक
├── files/                      # फ़ाइल अनुलग्नक
└── backups/                    # बैकअप फ़ाइलें
```

## अक्सर पूछे जाने वाले प्रश्न

### macOS: «ऐप्लिकेशन क्षतिग्रस्त है» या «डेवलपर को सत्यापित नहीं किया जा सकता» संदेश

चूँकि ऐप्लिकेशन Apple द्वारा हस्ताक्षरित नहीं है:

**1. «किसी भी स्रोत» से ऐप्लिकेशन चलाने की अनुमति दें**
```bash
sudo spctl --master-disable
```

फिर **सिस्टम सेटिंग्स → गोपनीयता और सुरक्षा → सुरक्षा** में जाएँ, **किसी भी स्रोत** चुनें।

**2. क्वारंटाइन विशेषता हटाएँ**
```bash
sudo xattr -dr com.apple.quarantine /Applications/AxInvest.app
```

**3. macOS Ventura+ अतिरिक्त चरण**
**सिस्टम सेटिंग्स → गोपनीयता और सुरक्षा** में जाएँ, **फिर भी खोलें** पर क्लिक करें।
